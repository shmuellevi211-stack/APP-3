# בצאתי מירושלים — גרסה 1.0

## עדכון תמונת האפליקציה והווידג׳ט
- הוחזרה התמונה המקורית שהועלתה, כולל רקע הנייר, גם לסמל האפליקציה וגם לכל פריסות הווידג׳ט.
- התמונה נוצרת מאותו קובץ מקור JPEG לשני המשאבים, כדי למנוע הבדלים בין הסמל לווידג׳ט.
- נשמרים שיפורי הגדלים, התאמת ארבע ערכות הצבעים למראה האפליקציה, והמבנה היחיד של הווידג׳ט.
- הוסרו ממסך מדריך ההפעלה הסעיפים ״בדיקת תמיכה בווידג׳טים״ ו״גדלי ווידג׳ט״.

## גרסה
שם הגרסה המוצג נשאר 1.0. קוד הגרסה הפנימי הועלה ל־15 כדי ש־Android יוכל להתקין את העדכון מעל גרסת 1.0 הקודמת.

## תאימות
Android 4.4/API 19 ומעלה.
