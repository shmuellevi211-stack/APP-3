# בצאתי מירושלים — גרסה 1.2

## תצוגת הווידג׳טים
תמונת בית המקדש הוסרה מכל הווידג׳טים. בכל שלושת הגדלים מניין הימים מופיע במרכז ובולט יותר מהכיתוב ומהפסוק.

- **קטן:** מספר 26sp, כיתוב 13sp ופסוק 10sp.
- **בינוני:** מספר 36sp, כיתוב 18sp ופסוק 14sp.
- **גדול:** מספר 50sp, כיתוב 19sp ופסוק 16sp.

## התאמה אישית
- צבע הווידג׳טים יכול להתאים אוטומטית לעיצוב האפליקציה, או להישאר בצבע נפרד: כחול, ירוק, לבן או שחור.
- מועד עדכון המניין ניתן לבחירה: חצות לפי שעון המכשיר (ברירת מחדל), או צאת הכוכבים בירושלים לפי אומדן אסטרונומי. שמירת הבחירה מעדכנת מיד את המונה ואת הווידג׳טים; מקש 0 מרענן אותם ידנית.
- מידת עיגול הפינות משפיעה על רקעי הווידג׳טים בלבד; מראה האפליקציה נשאר קבוע: ללא (0dp), עדין (8dp), רגיל (10dp — ברירת מחדל), בינוני (14dp) או מלא (22dp).

## סמל האפליקציה
התמונה שסופקה משמשת כסמל האפליקציה, כולל המסגרת, איור בית המקדש והכיתוב בעברית.

## ניווט
הניווט נעשה באמצעות מקשי החצים ומקש האישור. מקש 0 משמש לרענון ידני של המניין.

## גרסה והתקנה
שם הגרסה הוא 1.2 וקוד הגרסה הפנימי הוא 24. לאחר התקנה, מומלץ להסיר ווידג׳ט ישן ממסך הבית ולהוסיף אותו מחדש.

תאימות: Android 4.4/API 19 ומעלה.
