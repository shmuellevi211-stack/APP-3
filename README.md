# בצאתי מירושלים — גרסה 2.4.3

## תיקוני ווידג׳ט
- תמונת הווידג׳ט היא קובץ התמונה שהמשתמש העלה, בלבד; הקובץ נשמר בפרויקט כ־JPEG ומומר למשאב בזמן הבנייה.
- תוקנה פקודת RemoteViews לשינוי הרקע: הווידג׳ט משתמש ב־setBackgroundColor הנתמך ב־Android 4.4 במקום setBackgroundResource.
- מזהה קו ההפרדה קיים בכל פריסות הווידג׳ט, לרבות פריסה רחבה, כדי שלא תיכשל החלת RemoteViews כאשר משגר הבית בוחר פריסה זו.
- מידות ברירת המחדל צומצמו ל־40×110dp עבור הפריסה הצרה, במטרה להתאים למסכים קטנים; פריסות גדולות זמינות לפי שטח המסך ומשגר הבית.
- התמונה מוצגת ב־fitCenter כדי לשמור על התמונה בשלמותה ולא לחתוך את המסגרת שלה.
- הווידג׳ט משתמש בערכת הצבעים שנבחרה באפליקציה.
- במסך מדריך הפעלה נוספה בדיקת תמיכה של המכשיר בווידג׳טים ומספר ספקי הווידג׳ט שהמערכת מזהה.

## מגבלת משגר
אפליקציה יכולה לפרסם AppWidgetProvider, אך הוספה למסך הבית דורשת שמשגר הבית יממש AppWidgetHost ויתמוך בהוספת ווידג׳טים. אם המשגר של המכשיר אינו תומך בכך, שינוי בתוך APK האפליקציה אינו יכול להוסיף ווידג׳ט למסך הבית; בדיקת התמיכה באפליקציה מציגה את המידע שהמערכת מפרסמת.

## בנייה
האפליקציה תומכת ב־Android API 19 ומעלה. GitHub Actions מריץ בדיקות יחידה, בונה APK מסוג debug ומעלה artifact בשם `zohkrim-debug-apk`.
