# בצאתי מירושלים — גרסה 2.4.5

## משמעות השם
השם „בצאתי מירושלים” לקוח מן הקינה „אש תוקד בקרבי” הנאמרת בתשעה באב. הקינה משווה בין יציאת מצרים, שהייתה יציאה לחירות, לבין היציאה מירושלים שבאה בעקבות החורבן והגלות. היא מבטאת את האבל והגעגוע לירושלים ולבית המקדש ואת התקווה לשוב ולבנותם.

## תיקוני ווידג׳ט
- נשמר ספק AppWidget יחיד, כמו במבנה הגרסה הישנה.
- תיקון בחירת הפריסה: קודם נבדק גובה הווידג׳ט ורק אחר כך רוחבו, כדי שווידג׳ט צר וגבוה לא ייבחר בטעות כפריסה צרה.
- רענון בעקבות עדכון האפליקציה, אתחול המכשיר ושינוי תאריך/שעה.
- שימוש בתמונת המשתמש בלבד גם כסמל וגם בתמונה המוצגת בווידג׳ט.

## תאימות
Android API 19 ומעלה. הוספת ווידג׳ט ושינוי גודלו תלויים גם בתמיכת משגר מסך הבית.
