# זוכרים ומצפים — גרסה 2.0

אפליקציית Android בעברית, לא מקוונת, לזיכרון ירושלים ולמניין הימים מאז **5 באוגוסט שנת 70 לספירה**. אין מסך הגדרת תאריך ואין אפשרות לשנות את תאריך הבסיס.

## מה חדש ב־2.0

- תאריך בסיס קבוע: 5 באוגוסט 70 לספירה.
- מסך מצומצם למסכים קטנים, לרבות 240×320.
- ניווט במקשי החצים ואישור; במקלדת מספרית: 2/8 למעבר בין הכפתורים, 4 להצגת משפט אחר, 6 להחלפת עיצוב, ו־5 להפעלת הכפתור שבמיקוד.
- ארבע ערכות צבעים ומשפטים ממקורות יהודיים, עם שמירת בחירת העיצוב והמשפט.
- ווידג׳ט Android למסך הבית שמציג את מניין הימים ולחיצה עליו פותחת את האפליקציה.
- סמל אפליקציה בגווני כחול כהה וזהב.

## תאימות ווידג׳ט ב־Qin 1S

האפליקציה כוללת רכיב AppWidget תקני המתאים ל־Android API 19. הצגתו במסך הבית תלויה בכך שמשגר מסך הבית (launcher) במכשיר תומך בווידג׳טים ומאפשר להוסיף אותם. בחלק מקושחות הטלפונים עם מקשים התפריט הזה אינו קיים; במקרה כזה קוד האפליקציה לבדו אינו יכול להוסיף ווידג׳ט למסך הבית. יש לבדוק זאת במכשיר.

## בנייה אוטומטית

GitHub Actions בונה APK מסוג debug בכל push ל־main/master וגם בהרצה ידנית מתוך לשונית Actions.

הקובץ הצפוי: `app/build/outputs/apk/debug/app-debug.apk`

לאחר שהריצה מסתיימת בהצלחה, לפתוח את ריצת **Build Android APK** ב־Actions ולהוריד את ה־artifact בשם `zohkrim-debug-apk`.

## בנייה מקומית

נדרשים JDK 17, Android SDK Platform 33 ו־Gradle 7.6.4. פרויקט Gradle מפיק את קובץ ה־PNG מתוך קובץ הטקסט של הסמל בזמן `preBuild`, כך שאין צורך לייצר את הסמל ידנית.

מתוך תיקיית הפרויקט:

```sh
gradle assembleDebug --stacktrace --no-daemon
```

## חישוב המניין

החישוב משתמש ביום האזרחי המקומי ומשווה גבולות יום ב־UTC, כדי ששינויי שעון קיץ לא יגרמו להסטה של יום. תאריך 5 באוגוסט 70 לספירה מחושב לפי הלוח היוליאני ההיסטורי עבור התקופה שלפני תיקון הלוח הגרגוריאני.
