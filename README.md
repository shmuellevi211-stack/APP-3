# בצאתי מירושלים — גרסה 1.1

## עיצוב הווידג׳טים

תמונת בית המקדש הוסרה מכל הווידג׳טים. שלושת הגדלים מציגים כעת את מניין הימים במרכז, עם היררכיה שבה המספר גדול ובולט משמעותית מהכיתוב ומהפסוק.

- **קטן:** מספר 26sp, כיתוב 13sp ופסוק 10sp.
- **בינוני:** מספר 36sp, כיתוב 18sp ופסוק 14sp.
- **גדול:** מספר 50sp, כיתוב 19sp ופסוק 16sp.

העיצוב שומר על רקעי הצבע המקוריים ועל בחירת צבע עצמאית לווידג׳ט או התאמה לצבע האפליקציה.

## סמל האפליקציה

התמונה שסופקה משמשת כסמל האפליקציה, כולל המסגרת, איור בית המקדש והכיתוב בעברית.

## בחירות נוספות

- צבע עצמאי לווידג׳ט: כחול, ירוק, לבן או שחור; אפשר גם להתאים אוטומטית לצבע האפליקציה.
- החלפת המניין בחצות הלילה (ברירת מחדל) או בצאת הכוכבים בירושלים (אומדן אסטרונומי).

## גרסה והתקנה

שם הגרסה המוצג הוא 1.1. קוד הגרסה הפנימי הועלה ל־22.
כדי לרענן ווידג׳ט קיים, הסר אותו ממסך הבית והוסף אותו מחדש מרשימת הווידג׳טים של Android.

## תאימות

Android 4.4/API 19 ומעלה.


## ניווט והפעלה
הניווט באפליקציה נעשה באמצעות מקשי החצים, והכפתור המסומן מופעל באמצעות אישור או Enter. קיצורי המקשים המספריים הוסרו. במדריך ההפעלה ניתן לגלול בעזרת החצים ולסגור באמצעות אישור או הכפתור ״סגירה״.
