# בצאתי מירושלים — גרסה 1.0

## שלושה סוגי ווידג׳טים

### ווידג׳ט קטן
- שומר על המראה הקומפקטי שהיה בווידג׳ט הבינוני לפני הגדלתו.
- תמונת בית המקדש מוגדלת ל־48dp.
- המספר, הכיתוב והפסוק נשארים בגודל הקומפקטי.

### ווידג׳ט בינוני
- תמונת בית המקדש גדולה יותר (56dp).
- המספר, הכיתוב והפסוק הוגדלו, והפסוק יכול להופיע בשתי שורות.

### ווידג׳ט גדול
- תמונת בית המקדש המקורית עם רקע הנייר בחלק העליון.
- מספר הימים גדול ובולט מתחת לתמונה.
- הכיתוב ״ימים בלי בית מקדש״ והפסוק מופיעים מתחת למספר.

## בחירות נוספות
- צבע עצמאי לווידג׳ט: כחול, ירוק, לבן או שחור; אפשר גם להתאים אוטומטית לצבע האפליקציה.
- החלפת המניין בחצות הלילה (ברירת מחדל) או בצאת הכוכבים בירושלים (אומדן אסטרונומי).

## תמונה וגרסה
התמונה המקורית שהועלתה, כולל רקע הנייר, משמשת גם לסמל האפליקציה וגם לווידג׳טים.
שם הגרסה המוצג נשאר 1.0. קוד הגרסה הפנימי הועלה ל־18.

## התקנה
כדי לראות את שלוש האפשרויות, הסר ממסך הבית את הווידג׳ט הקיים, פתח את רשימת הווידג׳טים של Android ובחר ״ווידג׳ט קטן״, ״ווידג׳ט בינוני״ או ״ווידג׳ט גדול״.

## תאימות
Android 4.4/API 19 ומעלה.
