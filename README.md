# בצאתי מירושלים — גרסה 1.0

## עדכון עיצוב הווידג׳ט
- הווידג׳ט הבינוני מציג מספר, תווית ופסוק בגודל גדול יותר.
- בווידג׳ט הגדול תמונת בית המקדש ממוקמת בחלק העליון, ומתחתיה מספר גדול, הכיתוב ״ימים בלי בית מקדש״ והפסוק.
- הווידג׳ט משתמש באותה ערכת צבעים שנבחרה באפליקציה: כחול, ירוק, לבן או שחור. בחירת העיצוב באפליקציה מרעננת גם את הווידג׳ט.
- תמונת בית המקדש היא התמונה המקורית שהועלתה, לאחר הסרת רקע הנייר ושמירה כ־PNG שקוף. אותו ציור משמש גם כסמל האפליקציה.
- שם הגרסה המוצג באפליקציה ובפרטי Android הוא 1.0. קוד העדכון הפנימי הועלה כדי לאפשר התקנה מעל גרסאות קודמות.

## מבנה ווידג׳ט ותאימות
נשמר ספק ווידג׳ט יחיד ומנגנון שינוי הגודל של הגרסה שעבדה בעבר. הפריסות מותאמות ל־Android 4.4/API 19 ומעלה.
