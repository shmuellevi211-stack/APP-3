# בצאתי מירושלים — גרסה 2.4

הווידג׳ט עודכן לפי התמונה שבחרת: תמונת בית המקדש, כרטיס בגוון שנהב, מסגרת זהובה, מניין ימים חי, הכיתוב „ימים בלי בית מקדש” והפסוק שנבחר באפליקציה.

תמונת בית המקדש בווידג׳ט נחתכה מתוך אזור התמונה בדוגמה ששלחת. המספר והפסוק נשארים דינמיים ואינם חלק מתמונה סטטית.

גדלים לבחירה: 1×3, 1×4, 2×2, 3×2, 3×3, 4×1, 4×2, 4×3 ו־5×1. הגדלים הזמינים בפועל תלויים במשגר מסך הבית.

האפליקציה מיועדת ל־Android API 19 ומעלה, ונבנית אוטומטית ב־GitHub Actions כ־APK מסוג debug.
