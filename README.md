# זוכרים ומצפים

אפליקציית Android בעברית למעקב אחר מספר הימים מתאריך התחלה שנבחר, עם ממשק מימין לשמאל, ארבע ערכות צבעים, משפטים ממקורות יהודיים ושמירה מקומית. האפליקציה אינה דורשת אינטרנט בזמן השימוש.

## תאימות

- Android 4.4.4 ומעלה (API 19).
- מסך לאורך; הממשק ניתן לגלילה כדי להתאים גם למסכים קטנים.
- היעד הוא Xiaomi Qin 1S, אך יש לאמת התקנה ותפעול במכשיר עצמו.
- זו גרסת בסיס; היא אינה מחליפה בדיקה במכשיר פיזי.

## בנייה אוטומטית

GitHub Actions אמור לבנות APK מסוג debug בכל push ל-main/master וגם בהרצה ידנית מתוך לשונית Actions.

הקובץ הצפוי: `app/build/outputs/apk/debug/app-debug.apk`

לאחר שהריצה מסתיימת בהצלחה, יש לפתוח את ריצת Build Android APK ב-Actions ולהוריד את ה-artifact בשם `zohkrim-debug-apk`. אם הבנייה נכשלת, יש לבדוק את שלב Build Android APK ואת יומן השגיאות.

## בנייה מקומית

נדרשים JDK 17, Android SDK Platform 33 ו-Gradle 7.6.4. מתוך תיקיית הפרויקט:

```sh
gradle assembleDebug --stacktrace --no-daemon
```

## התנהגות המונה

המשתמש בוחר תאריך התחלה. ביום ההתחלה מוצג 0; לאחר מכן מוצגים מספר הימים הקלנדריים שחלפו. בחירת התאריך והעיצוב נשמרות במכשיר.
