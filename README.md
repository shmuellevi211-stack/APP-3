# בצאתי מירושלים — גרסה 2.4.4

## תיקון תאימות ווידג׳ט
- חזרנו לספק AppWidget יחיד, כמו במבנה של הגרסה הישנה שבה הווידג׳ט עבד. מסירים את הכפילות של תשעה ספקים נוספים ומוסיפים ווידג׳ט אחד שניתן לשינוי גודל.
- גודל ברירת המחדל הוקטן ל־40×110dp כדי להתאים למסכים קטנים.
- נשמרת בחירת פריסה לפי גודל, הצגת מניין הימים והפסוק, והצגת תמונת בית המקדש שהועלתה.
- הווידג׳ט מתרענן גם לאחר עדכון האפליקציה (MY_PACKAGE_REPLACED), כדי למנוע הצגת תמונה ישנה שנשמרה אצל משגר הבית.
- הוסרו קריאות RemoteViews מותאמות לשינוי רקע; נשארו פעולות סטנדרטיות בלבד לעדכון טקסט, צבע טקסט ולחיצה.

## התמונה
תמונת הווידג׳ט היא התמונה שהמשתמש העלה בלבד, המשולבת במשאב `widget_temple_scene`. היא מוצגת ביחס המקורי, ללא חיתוך.

## שימוש
פותחים את תפריט הווידג׳טים במסך הבית, בוחרים „בצאתי מירושלים”, מוסיפים את הווידג׳ט ומשנים את גודלו לפי האפשרויות שמשגר מסך הבית מאפשר.

## תאימות
האפליקציה מיועדת ל־Android API 19 ומעלה. הוספה ושינוי גודל בפועל מחייבים תמיכה בווידג׳טים מצד משגר מסך הבית.
