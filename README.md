# בצאתי מירושלים — גרסה 2.3

אפליקציית Android בעברית לזיכרון ירושלים, עם מניין ימים קבוע מתאריך הייחוס 5 באוגוסט 70 לספירה.

## תיקוני גרסה 2.3

- הוסרה גרסת האפליקציה מכותרת המסך הראשי.
- תוקן שם האפליקציה שמופיע במסך הבית: בצאתי מירושלים.
- מסך מדריך הפעלה ואודות סודר מחדש לכרטיסיות עם כותרות, ריווח וטקסט קריא יותר.
- סמל חדש ומינימליסטי בגווני כחול וזהב.
- נוספו אפשרויות ווידג׳ט נפרדות לבחירה: 1×3, 1×4, 2×2, 3×2, 3×3, 4×1, 4×2, 4×3 ו־5×1.
- הווידג׳ט מתעדכן לפי המניין והפסוק שנבחר באפליקציה, ללא הצגת תאריך.
- נשמרה תמיכה במקשי החצים, אישור ובמקשי המספרים במכשירים תואמים.

## שימוש בווידג׳טים

במסך הבית פתחו את תפריט הווידג׳טים ובחרו את הפריסה הרצויה לפי שמה (למשל, "בצאתי מירושלים — 4×1"). אפשר לשנות גודל לאחר ההוספה, אם משגר מסך הבית תומך בכך. זמינות הווידג׳טים והגודל המדויק בפועל תלויים במשגר ובתאי מסך הבית.

## תאימות

האפליקציה מוגדרת ל־Android API 19 ומעלה, עבור מכשירים כגון Xiaomi Qin 1S. הצגת ווידג׳טים תלויה בתמיכת משגר מסך הבית של הקושחה.

## בנייה אוטומטית

GitHub Actions בונה APK מסוג debug בכל push ל־main/master וגם בהרצה ידנית. בסיום בנייה מוצלחת, הורידו את ה־artifact בשם `zohkrim-debug-apk` מתוך לשונית Actions.

## בנייה מקומית

נדרשים JDK 17, Android SDK Platform 33 ו־Gradle 7.6.4.

```sh
gradle assembleDebug --stacktrace --no-daemon
```
