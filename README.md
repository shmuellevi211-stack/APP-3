# בצאתי מירושלים — גרסה 2.4.7

## שחזור הווידג׳ט לגרסה 2.2
בהשוואת Git בין 2.2 ל־2.3 נמצא שב־2.3 נוספו תשעה ספקי ווידג׳ט נפרדים (1×3, 1×4, 2×2, 3×2, 3×3, 4×1, 4×2, 4×3, 5×1), יחד עם תשעה קובצי metadata ומחלקות Provider נוספות. בנוסף עודכנו קוד הווידג׳ט ורישום ה־Manifest.
ב־2.4.7 הוחזרו קוד הווידג׳ט, שלוש פריסות ה־XML והגדרת AppWidget של 2.2, שהיו הגרסה האחרונה שעבדה:
- ספק ווידג׳ט יחיד.
- פריסות צרה, קומפקטית ורחבה.
- גודל מינימום 40×180dp, גודל שינוי מינימלי 40×36dp ועדכון כל 30 דקות.
- תמונת הווידג׳ט נטענת ממשאב סמל האפליקציה `ic_launcher`.
- אין הרשאת `RECEIVE_BOOT_COMPLETED` ואין מסנן `BOOT_COMPLETED` במניפסט.
- מדריך ההפעלה עודכן להסביר שמוסיפים ווידג׳ט אחד ומשנים את גודלו במסך הבית, במקום לבחור ספקי גודל נפרדים.

## הרשאת הפעלה בעת אתחול
ההרשאה `RECEIVE_BOOT_COMPLETED` לא הייתה חלק משינויי 2.3. היא נוספה בקומיט נפרד מאוחר יותר, לצורך רענון בזמן אתחול, והוסרה בגרסה 2.4.6. בגרסה 2.4.7 היא אינה מבוקשת.

## תאימות
Android API 19 ומעלה. תמיכה בהוספה ובשינוי גודל תלויה גם במשגר מסך הבית.
