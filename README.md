# בצאתי מירושלים — גרסה 1.0

## עדכוני גרסה 1.0
- התמונה המקורית שהועלתה, כולל רקע הנייר, משמשת גם לסמל האפליקציה וגם לכל פריסות הווידג׳ט.
- נשמרים ארבעת עיצובי הצבע: כחול, ירוק, לבן ושחור.
- נוספה בחירה בין צבע ווידג׳ט עצמאי לבין התאמה אוטומטית לצבע האפליקציה.
- בחירת סוג הגודל של הווידג׳ט נשמרת לאחר שינוי הגודל במסך הבית, כדי למנוע החלפת פריסה לאחר אתחול המכשיר.
- מדריך ההפעלה נשאר ממוקד בהפעלה ובשימוש, ללא סעיפי בדיקת תמיכה בווידג׳טים או הסברים על גדלי ווידג׳טים.
- נוספה בחירה בין החלפת מניין הימים בחצות הלילה (ברירת מחדל) לבין צאת הכוכבים. חישוב צאת הכוכבים הוא אומדן אסטרונומי לפי ירושלים, כאשר מרכז השמש נמצא כ־8.5 מעלות מתחת לאופק; הוא אינו מותאם למיקום אחר או לכל מנהג הלכתי.

## גרסה
שם הגרסה המוצג נשאר 1.0. קוד הגרסה הפנימי הועלה ל־16 כדי לאפשר התקנה מעל גרסת 1.0 הקודמת.

## תאימות
Android 4.4/API 19 ומעלה.
