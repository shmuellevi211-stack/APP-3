# זוכרים ומצפים

אפליקציית Android בעברית למעקב אחר מונה ימים, עם ממשק RTL, ערכות צבעים, משפטים ממקורות יהודיים ושמירה מקומית.

## תאימות ובנייה
- מיועד ל-Android 4.4 (API 19) ומעלה.
- Java + Android SDK קלאסי, ללא חיבור רשת בזמן הריצה.
- GitHub Actions בונה APK מסוג debug ומעלה אותו כ-artifact.
- תאימות ל-Xiaomi Qin 1S ווידג'טים דורשת בדיקה במכשיר עצמו.

## בנייה מקומית
נדרשים JDK 11, Android SDK Platform 28 ו-Build Tools 28.0.3, ו-Gradle 5.6.4.

```sh
gradle assembleDebug
```

הקובץ נוצר ב-`app/build/outputs/apk/debug/app-debug.apk`.

## חישוב המונה
הגרסה הראשונית משתמשת בתאריך התחלה שהמשתמש בוחר. היא אינה מציגה תאריך היסטורי לא מאומת כעובדה. החישוב מבוסס על ימים קלנדריים מקומיים ומחריג את יום ההתחלה (ביום ההתחלה מוצג 0).

## סטטוס
גרסת בסיס ראשונית. יש להמתין להצלחת GitHub Actions כדי לאשר קומפילציה, ולבדוק את ה-APK במכשיר אמיתי לפני הפצה.
