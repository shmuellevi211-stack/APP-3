# בצאתי מירושלים — גרסה 2.4.1

## תיקוני יציבות ודיוק
- חישוב מניין הימים משתמש בלוח גרגוריאני פרולפטי, בלי תיקון קבוע של יומיים ובלי מעבר אוטומטי ללוח היוליאני בתאריך הייחוס.
- נוספו בדיקות יחידה לחישוב התאריך הקבוע, היום הבא, שנה מעוברת ותאריכים לא תקינים.
- ערכי העיצוב והפסוק נטענים באופן בטוח גם אם נשמרו ערכים פגומים בהעדפות.
- תיקון בחירת פריסת הווידג׳ט כך ש־3×3 משתמש בפריסה הרחבה, וגדלים צרים/ריבועיים/אופקיים נבחרים לפי המידות.
- עודכנו מידות המינימום של כל פריסות הווידג׳ט כדי להתאים טוב יותר לתאי מסך הבית.

## ווידג׳ט
התצוגה כוללת את תמונת בית המקדש, כרטיס שנהב עם מסגרת זהובה, מניין ימים חי, הכיתוב „ימים בלי בית מקדש” והפסוק שנבחר באפליקציה. גדלים לבחירה: 1×3, 1×4, 2×2, 3×2, 3×3, 4×1, 4×2, 4×3 ו־5×1. הזמינות והגודל בפועל תלויים במשגר מסך הבית.

## בנייה
האפליקציה תומכת ב־Android API 19 ומעלה. GitHub Actions מריץ תחילה `gradle testDebugUnitTest`, לאחר מכן בונה APK מסוג debug ומעלה את התוצר כ־artifact `zohkrim-debug-apk`.
