# בצאתי מירושלים — גרסה 2.2

אפליקציית Android בעברית לזיכרון ירושלים, עם מניין ימים קבוע מאז 5 באוגוסט שנת 70 לספירה. אין צורך להגדיר תאריך בתוך האפליקציה.

## מה כלול ב־2.1

- שם האפליקציה: בצאתי מירושלים.
- מניין ימים מתוקן; החישוב מפחית את הסטייה ההיסטורית בת יומיים שנמצאה בגרסה הקודמת.
- תווית מניין: "ימים בלי בית מקדש" ללא הצגת תאריך במסך הראשי או בווידג׳ט.
- כפתור "מדריך הפעלה ואודות", כולל מקשי ניווט ופרטי היוצר: "האפליקציה פותחה ע״י שמואל_770 מפורום מתמחים טופ".
- ווידג׳ט למסך הבית הכולל סמל/תמונת בית המקדש, מספר הימים, הכיתוב "ימים בלי בית מקדש" ופסוק מהאפליקציה.
- הווידג׳ט ניתן לשינוי גודל אופקי ואנכי. אפשר לנסות גדלים כגון 1×3, ‏4×1 ו־4×3; הגדלים המדויקים הזמינים תלויים במשגר מסך הבית ובגודל התא במכשיר.
- תמיכה במקשי החצים ואישור; במקלדת מספרית: 2/8 למעבר בין הכפתורים, 4 להצגת משפט אחר, 6 להחלפת עיצוב, ו־5 להפעלת הכפתור שבמיקוד.

## תאימות ווידג׳ט ב־Xiaomi Qin 1S

האפליקציה כוללת רכיב AppWidget תקני המתאים ל־Android API 19. הצגת הווידג׳ט תלויה בכך שמשגר מסך הבית במכשיר תומך בווידג׳טים ומאפשר להוסיף אותם. בחלק מקושחות הטלפונים עם מקשים התפריט הזה אינו קיים; יש לבדוק זאת במכשיר.

## בנייה אוטומטית

GitHub Actions בונה APK מסוג debug בכל push ל־main/master וגם בהרצה ידנית מתוך לשונית Actions. לאחר שהריצה מסתיימת בהצלחה, לפתוח את ריצת **Build Android APK** ב־Actions ולהוריד את ה־artifact בשם `zohkrim-debug-apk`.

## בנייה מקומית

נדרשים JDK 17, Android SDK Platform 33 ו־Gradle 7.6.4.

```sh
gradle assembleDebug --stacktrace --no-daemon
```

## חישוב המניין

החישוב משתמש ביום האזרחי המקומי ומשווה גבולות יום ב־UTC כדי למנוע שגיאות עקב שעון קיץ. בגרסה 2.2 נוספה התאמה של יומיים כדי להתאים למניין המאומת שהוגדר לפרויקט.


בגרסה 2.2: סמל חדש עם איור בית המקדש, ווידג׳ט עם תמונת בית המקדש והפסוק הנבחר באפליקציה. הווידג׳ט מתאים לפריסות צרה 1×3, קומפקטית 4×1 ורחבה 4×3; הגודל המדויק תלוי במשגר וניתן לשינוי בלחיצה ארוכה.
