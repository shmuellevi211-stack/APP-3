# בצאתי מירושלים — גרסה 1.0

## שני סוגי ווידג׳טים
האפליקציה מציגה כעת שני פריטים נפרדים ברשימת הווידג׳טים של Android, כדי שאפשר יהיה לבחור את העיצוב כבר בזמן ההוספה למסך הבית.

### ווידג׳ט בינוני
- מספר הימים והכיתוב מוגדלים.
- הפסוק מוצג בגודל קריא יותר ויכול להופיע בשתי שורות.
- תמונת בית המקדש המקורית עם רקע הנייר מוצגת לצד הטקסט.

### ווידג׳ט גדול
- תמונת בית המקדש המקורית עם רקע הנייר בחלק העליון.
- מספר הימים גדול ובולט מתחת לתמונה.
- הכיתוב ״ימים בלי בית מקדש״ והפסוק מופיעים מתחת למספר.

## בחירות נוספות
- צבע עצמאי לווידג׳ט: כחול, ירוק, לבן או שחור; אפשר גם להתאים אוטומטית לצבע האפליקציה.
- החלפת המניין בחצות הלילה (ברירת מחדל) או בצאת הכוכבים בירושלים (אומדן אסטרונומי).

## תמונה וגרסה
התמונה המקורית שהועלתה, כולל רקע הנייר, משמשת גם לסמל האפליקציה וגם לווידג׳טים.
שם הגרסה המוצג נשאר 1.0. קוד הגרסה הפנימי הועלה ל־17.

## התקנה
כדי לראות את שתי האפשרויות, יש להסיר ממסך הבית את הווידג׳ט הישן, ואז לפתוח את רשימת הווידג׳טים של Android. שם יופיעו שתי בחירות נפרדות: ״ווידג׳ט בינוני״ ו״ווידג׳ט גדול״.

## תאימות
Android 4.4/API 19 ומעלה.
